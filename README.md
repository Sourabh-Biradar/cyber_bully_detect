### project : Cyber Bullying Detection

- data scource :
  1. the Gab hate corpus : https://osf.io/edua3/
  2. jigsaw toxic comments : https://www.kaggle.com/competitions/jigsaw-toxic-comment-classification-challenge/data
  3. twitter dataset : https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification
 
- tools used :
  1. DVC : for data version control
  2. git : for version control
  3. poetry : for dependencies management
  4. docker : for containerization
  5. gcp : for cloud storage
  5. makefile : for cmd shortcuts & workflow

- cmds :
    - make version-data
      
- code template : https://github.com/emkademy/cybulde-project-template
